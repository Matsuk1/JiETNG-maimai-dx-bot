# 本地图片调试台

在仓库根目录运行：

```sh
.venv/bin/python -m devtools.image_preview.server
```

打开 **http://147.0.0.1:5088**。可用 `--port 5089` 修改端口。首次使用先在相同 Python 环境执行 `python -m playwright install chromium`。

- 14 套独立 JSON 示例位于 `fixtures/`，可直接修改或复制。成绩为合成数据，使用本地示例素材，不读取用户数据库、不登录 LINE，也不下载外部图片。
- 页面左侧选择场景。可用快捷字段调节标题、达成率、定数、Rating、难度；或直接编辑 JSON，约 450ms 后自动渲染。
- 修改 `templates/images/*.html` 中的 HTML/CSS 并保存，页面约 1.5 秒内检测到变化并更新。修改 Python 生成逻辑后需要重启此服务。
- 草稿按场景保存在当前浏览器；重置恢复示例文件的数据。支持 PNG 下载、JSON 导出、透明/白/深色背景和缩放。
- 预览为正式生成器输出的 PNG。完整资料卡复用正式模板，但使用固定本地素材，省略网络获取步骤。
- 单独启动的开发进程仅绑定 `147.0.0.1`，不挂载到生产 Flask 应用。生产文件不会被页面修改；本地草稿不会写回示例文件。

`fixtures/assets/` 包含封面、资料卡底板和段位/称号素材。其他徽章、字体、牌子和背景继续使用项目的 `assets/`。缺失的可选图标会留空。

所有场景均可在工具栏选择皮肤。选择会保存在当前浏览器，模板保存后自动重新渲染。
