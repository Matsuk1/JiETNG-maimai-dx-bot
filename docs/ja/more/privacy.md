# プライバシーポリシー

## 概要

JiETNG は個人が保守する maimai DX スコア管理ツールです。このページでは現在のプロジェクトが収集・処理する可能性のあるデータを説明します。

## データ元

- **SEGA アカウント同期**：連携ページで SEGA ID、パスワード、サーバー、Aime を入力し、maimai NET から成績を同期します。
- **Import Token 取り込み**：設定ページでユーザー Import Token を作成し、ブックマークレットまたは信頼できるツールが加工済み `profile`、`best`、`recent` をアップロードします。

## 保存されるデータ

LINE ユーザー ID、言語/タイムゾーン/背景設定、SEGA 認証情報、サーバー、Aime、maimai プロフィール表示情報、Best/Recent、Import Token のハッシュと状態、開発者 Token、権限関係、コマンド利用イベント、エラーログを保存する場合があります。

Import Token の平文は一度だけ表示され、サーバーにはハッシュが保存されます。

## 利用目的

成績同期または取り込み、スコア画像と進捗表示の生成、設定/エクスポート/API 機能、不正利用防止、デバッグ、サービス安定化のために使います。

## 削除とエクスポート

LINE の個別チャットで `unbind` を送り、返信の Web ページを開いて確定します。リンクの有効期限は 10 分です。期限切れの場合は再送してください。確定すると JiETNG のユーザー情報、Best/Recent、カスタム背景、ニックネームキャッシュを削除します。Bot から元に戻すことはできません。

```text
export json
export xml
```

エクスポートは加工済み成績データです。解除時に過去のログ、生成画像、既存バックアップ内の全コピーが直ちに消去されるわけではありません。保存期間は運用設定に依存します。

## セキュリティ

- Web ページは HTTPS を使用します。
- 現在のアプリは SEGA パスワードをユーザー JSON に保存し、フィールド単位の暗号化を実装していません。保存時暗号化は保証できません。パスワードを預けたくない場合は Import Token モードを利用できます。
- Import Token と開発者 Token はパスワード同様に扱ってください。
- 撤回済み Token はアップロードやアクセスを継続できません。

## 公開範囲・体験ページ・画像

ランキング参加と他人のメンション検索は既定で有効で、`settings` で個別に無効化できます。許可済みアプリはデータへアクセスでき、owner 関連付けを含む権限はユーザーが設定から撤回できます。

オンライン体験は SEGA ID・パスワードを JiETNG に送り、そのログインと画像生成に使います。永続的な連携アカウントは作りません。「記憶」を有効にすると、ブラウザの `demo_creds` Cookie にパスワードを含む情報を 90 日間保存し、チェックを外すと消去します。ブックマークレットの Import Token は公式サイト上の localStorage に保存され、JP/INTL で別々です。

OCR は引用された LINE 画像をダウンロードして認識します。生成画像を一時ファイルとして LINE に提供する場合があります。認識だけでは個人成績を保存しません。カスタム背景はサーバーに保存され、ログ・バックアップ・一時画像の保持期間は運用設定に依存します。
