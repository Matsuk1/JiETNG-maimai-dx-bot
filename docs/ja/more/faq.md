# よくある質問

## SEGA ID は必須ですか？

必須ではありません。JiETNG は 2 つのモードに対応しています。

- SEGA アカウントを連携して `maimai update` を使う。
- Import Token モードでブックマークレットから成績をアップロードする。

maimai NET からの自動同期には完全な SEGA 連携が必要です。

## 始め方は？

1. 個別チャットで `bind` を送信します。
2. SEGA 連携、または Import Token モードを選びます。
3. SEGA ユーザーは `maimai update`、Import Token ユーザーは `settings` で token を作成して[ブックマークレット](/bookmarklet)を使います。
4. `b50`、`rct50`、`ヒバナ record`、`真極 plate` を試します。

## チャットに SEGA パスワードを送ってよいですか？

いいえ。JiETNG は LINE チャットでパスワード送信を求めません。連携 Web ページにのみ入力してください。

## Import Token とは？

加工済み成績 JSON をアップロードするためのユーザー単位の資格情報です。開発者 Token ではなく、他ユーザーにはアクセスできません。

平文は一度だけ表示されます。撤回後はアップロードできず、設定ページで削除できます。

## B50 が最新ではありません

クエリは JiETNG に保存済みの成績を使います。`maimai update` を実行するか、ブックマークレットで再アップロードしてください。

## rebind で SEGA ID を変えられますか？

いいえ。`rebind` はパスワード、サーバー、Aime の更新用です。別 SEGA ID にする場合は `unbind` 後に `bind` してください。

## エクスポートできますか？

```text
export json
export xml
```

加工済みプロフィール、Best、Recent、標準化済み成績フィールドを出力します。DB の生データではありません。

## メンション検索が失敗します

メンションされたユーザーが JiETNG に登録済みで、成績データを持っている必要があります。対象が存在しない場合、自分のデータにはフォールバックしません。

## 成績検索・ランキングを無効にできますか？

`settings` でメンション検索とランキング参加を個別に無効化できます。既定では両方有効です。この操作で開発者権限は撤回されないため、アプリ権限は別に管理してください。

## 画像の言語・背景が設定と違うのは？

対話言語と画像言語は別で、JP 画像は日本語、INTL は英語です。背景を使わないスキンもあります。スキン・背景スイッチ・選択画像を確認してください。

## rec で成績を取り込めますか？

できません。`rec`・`rec -flex`・`fix-rcd` は判定分析で、Best/Recent は保存しません。同期または Import Token のアップロードを利用してください。

## 最初の Import Token はどこですか？

取り込み専用登録の成功画面で作成し、その場で平文を一度だけ表示します。利用開始のために 2 個目を作る必要はありません。紛失時は `settings` で再作成し、不要な Token を撤回してください。書籤の古いタブキャッシュは[サポート](/more/support)を参照してください。
