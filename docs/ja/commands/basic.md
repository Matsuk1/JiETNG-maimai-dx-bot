# 基本コマンド

アカウント、設定、状態、エクスポート、サポート関連のコマンドです。特記がない限り大文字小文字は区別されません。

## アカウントと設定

```text
bind
```

個別チャットで連携リンクを送信します。SEGA 連携と Import Token モードに対応しています。

```text
rebind
```

完全な SEGA 連携ユーザー向けに、パスワード、サーバー、Aime を更新します。SEGA ID は変更できません。

```text
settings
```

設定ページを開きます。言語、タイムゾーン、背景、表示設定、Import Token を管理できます。

```text
profile
getme
```

プロフィールと連携状態を表示します。

個別チャットで `unbind` を送り、返信の Web ページで確定します。有効期限は 10 分です。JiETNG ユーザー情報・Best/Recent・カスタム背景・ニックネームキャッシュを削除し、Bot から元に戻すことはできません。

## 更新

```text
maimai update
update
```

maimai NET から最新成績を同期します。完全な SEGA 連携が必要で、自分自身にのみ作用します。

Import Token ユーザーはブックマークレットでアップロードしてください。

## エクスポート

```text
export json
export xml
```

DB の生データではなく、JiETNG が加工したプロフィール、Best、Recent、標準化済み成績フィールドを出力します。

## その他

```text
status
rank
rank jp
rank intl
```

`rank` / `ranking` は DX Rating ランキングを表示します。`jp` / `intl` を指定できます。

## 設定ページの機能

個別チャットで `settings` を送信します。リンクの有効期限は 30 分です。

- **言語・タイムゾーン**：対話は簡体字・繁体字中国語、英語、日本語に対応。画像内の文字はサーバーに従い、JP は日本語、INTL は英語です。
- **画像スキン**：提供中のスキンを選択できます。背景を使用しないスキンもあり、未対応テンプレートは既定に戻ります。
- **背景**：背景の有効化、選択、ぼかし・オーバーレイの調整。カスタム画像は最大 2 枚、各 5 MiB 以下。PNG、JPEG、WebP に対応し、HEIC/HEIF はサーバーのデコーダー対応も必要です。
- **ランキング・メンション**：ランキング参加と他人からのメンション検索を個別に無効化できます。未設定時は両方有効です。
- **Import Token**：作成、撤回、撤回済み Token の削除。平文は一度だけ表示されます。
- **アプリ権限**：連携先の確認と権限の撤回。アカウント作成元の owner 関連付けも撤回できます。

`rank` は同じサーバーの参加許可済み JiETNG ユーザーを対象とし、SEGA 全プレイヤーの公式順位ではありません。`rank jp` / `rank intl` は各サーバーの上位 15 人です。

`refreshmenu` は現在の連携状態に合う LINE メニューを再設定します。成功時の追加返信はありません。

## ヘルプ

`help` でカテゴリ一覧、`b50 -help`、`artist -help`、`rec -help` で対応コマンドの説明を表示します。内部ボタン操作すべてにチャット用ヘルプがあるわけではありません。本人専用コマンドで他人をメンションすると拒否されます。
