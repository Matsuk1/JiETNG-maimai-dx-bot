# 検索とフィルター

JiETNG の検索は、スコア画像フィルター、楽曲検索、楽曲 ID 検索に分かれます。

## スコア画像フィルター

```text
b50 -lv 14 14.9 -diff mas rem -scr 100.5
ab50 -ver buddies -type dx
ab50 -page 2
ap50 -lv 13.6
```

レベル/定数、単曲 Rating、達成率、DX スコア、DX 星、難易度、譜面種別、バージョン、ページで絞り込めます。

結果はスコア画像として描画されるため、定数帯 B50、MASTER/Re:MASTER のみ、特定バージョンのみなどの確認に使えます。

## 楽曲検索

```text
artist Nanahira
designer Jack
bpm 180
bpm 0-120
bpm 120-180
ヒバナ info
```

- `artist` はアーティスト名検索。
- `designer` は譜面制作者検索。
- `bpm` は BPM の完全一致または範囲検索。`0` から始まる範囲、`120-180`、`120~180`、`120 180` に対応。
- `info` は楽曲情報。
- キーワードは大文字小文字を区別しません。

## 楽曲レコード

```text
ヒバナ record
```

`record` は曲名または別名で個人成績を検索します。

## データ元

検索結果は JiETNG に保存済みの加工済み成績データを使います。データ元は `maimai update`、ブックマークレットの Import Token アップロード、またはユーザー Import Token による外部ツールからの取り込みです。

検索コマンドだけでは公式データを再同期しません。

## 検索の使い分け

`info`、`artist`、`designer`、`bpm`、`random` は曲庫を参照し、成績同期は不要です。`record`、`records`、B 系は保存済み個人成績を使います。曲庫はユーザーの JP/INTL 設定に従い、通常の既定は JP です。

`artist Nanahira 2`、`designer Jack 2` でページを指定できます。BPM 範囲は `bpm 120-180 2` のように明示すると確実です。`bpm 180 2` は BPM 180 の 2 ページ目、`bpm 120 180` は範囲です。

曲名・別名 で検索できます。通常検索の候補上限は 10 件なので広すぎる場合は絞ってください。曲情報・成績・Calc は返されたボタンから開けます。内部操作名を手入力する必要はありません。

レベルは `14`・`14+`、定数は `14.7`。`-ver` はバージョン名一致で、任意の部分文字列検索ではありません。詳細は[レコードコマンド](/commands/record)を参照してください。
